# BCL Cold Chain Logistics — GitHub Pages Website

A responsive, interactive academic business web app for **BCL Cold Chain Logistics**.

## Included
- Home / business purpose and logo
- About Business
- Services
- Shipment tracking (interactive)
- Instant quote calculator
- Operations dashboard with KPIs and chart
- Contact / enquiry form
- Purposeful internal links and mail/phone links
- Responsive design for desktop, tablet and mobile

## Files
```text
index.html
style.css
script.js
images/logo.svg
README.md
```

## GitHub Pages
1. Upload all files and the `images` folder to the repository root.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch → main → / (root)**.
4. Save and open the generated GitHub Pages URL.

No external logistics-company reference links are used in the site.

> Note: KPI values and calculator outputs are demonstration values for the academic business-app exercise.
